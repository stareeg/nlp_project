# Групповое задание №1: поиск юридических ссылок

Сервис на FastAPI. На вход получает текст, находит в нём ссылки вида `пп. 1 п. 2 ст. 3 НК РФ` и возвращает их списком:

```json
{"links": [{"law_id": 15, "article": "3", "point_article": "2", "subpoint_article": "1"}]}
```

## Как запустить

Через Docker:

```bash
docker build -t law-links-service .
docker run -d -p 8978:8978 --name law-links-container law-links-service
```

После старта нужно подождать секунд 5-6, пока строится индекс по `law_aliases.json`. Потом можно проверять:

```bash
curl -X POST "http://localhost:8978/detect" \
     -H "Content-Type: application/json" \
     -d '{"text": "Согласно статье 23 Налогового кодекса и ст. 145 Гражданского кодекса"}'
```

Swagger открывается на http://localhost:8978/docs.

Без Docker (нужен Python 3.9+):

```bash
pip install -r requirements.txt
python main.py
```

Остановить и удалить контейнер:

```bash
docker stop law-links-container
docker rm law-links-container
docker rmi law-links-service
```

## Тесты

```bash
python -m unittest -v
python tests/benchmark.py
python tests/benchmark.py --url http://localhost:8978/detect
```

`benchmark.py` это наш генератор размеченных текстов: 4 уровня по 250 штук, от простых ссылок до опечаток, цепочек из нескольких законов и записей вроде `ФЗ-152`. Туда же входит пример текста из условия. Флаг `--errors 10` показывает тексты, где что-то не совпало. 1000 запросов к сервису в Docker проходят примерно за 3 секунды.

## Как это работает

Без нейросетей, на правилах:

1. Текст приводим к нижнему регистру, чистим кавычки, тире и пробелы.
2. Названия законов ищем по словарю алиасов алгоритмом Ахо-Корасик, слова прогоняем через стеммер, чтобы находить «Гражданского кодекса». Если точного совпадения нет, пробуем найти название с опечаткой.
3. Перед названием (или сразу после него) ищем статьи, части, пункты и подпункты, перечисления разворачиваем в отдельные ссылки.
4. Часть статьи пишем в `point_article`. Если есть и часть, и пункт, то часть идёт в `point_article`, а пункт в `subpoint_article`.
5. «П. 3 указанной статьи» и «ст. 11 того же кодекса» привязываем к последней найденной ссылке.

Код лежит в `detector/`, сервис в `main.py`.
